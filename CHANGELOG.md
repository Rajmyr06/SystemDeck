# Changelog

## 1.1.0

- Notification permission status refreshes automatically when SystemDeck becomes active again.

- Per-core CPU activity in Performance
- Rolling-history labels shown as human-readable time ranges
- Battery voltage, current, power, cycle count, capacity, and health when exposed by macOS
- Adapter wattage and design capacity shown only when available
- Customizable menu bar metrics with up to three selections
- Optional threshold notifications for CPU, memory, storage, thermal pressure, and low battery
- Menu bar live strip now renders compact values directly in the macOS status bar
- 5-second battery/electrical refresh with live battery-power trend and clearer power-flow context

## 1.0.0

- CPU, memory, GPU, storage, network, battery, thermal, and process monitoring
- Rolling telemetry charts and compact/menu bar views
- Process CPU normalization and collector diagnostics
- Sleep/wake recovery and bounded history buffers
- Native full-screen and fit-to-screen window behavior
- Launch at Login support
- Local `.app`, `.zip`, and `.dmg` release packaging
